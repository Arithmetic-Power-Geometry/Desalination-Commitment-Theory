# Metrics

## Hidden commitment

A computational state is flagged when present desalination is zero while cumulative future desalination is positive.

## Avoidance multiplier

\[
K_D=\frac{V_D^0-V_D^I}{V_I}.
\]

## Preservation multiplier

\[
K_P=K_D-\eta,
\]

where \(\eta\) is the direct effective substitution fraction.

## Latest full-prevention time

`t_star` is the latest intervention delay for which the tested intervention eliminates cumulative desalination within numerical tolerance.

## Scientific interpretation

All quantities are conditional on the model, parameter set, intervention set, and planning horizon.
